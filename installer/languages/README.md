# Vendored Simplified Chinese installer messages

`ChineseSimplified.isl` is an **unmodified** official Inno Setup translation by
Zhenghan Yang (Kira), with the upstream attribution and translator information
preserved. It is a UTF-8 message catalog, not executable code. The catalog's header
declares compatibility with Inno Setup 6.5.0 and later.

The official translation was first added to `jrsoftware/issrc` on 2026-06-23,
after the 2026-05-26 release of the pinned Inno Setup 6.7.3 compiler. Consequently,
6.7.3 does not bundle this language even though the current translation web page
lists it as official. A repository copy avoids depending on a newer compiler or a
download during packaging.

Pinned upstream commit: `6ef32198ef1f7b7b375cd4b6b90896c2a58eb4c2` (2026-08-04).

The upstream Inno Setup License grants use, modification and redistribution under
its stated conditions. Its exact text is retained as `INNO-SETUP-LICENSE.txt`, and
the installer also places that file in `{app}\licenses\inno-setup`. No source
notices or Inno Setup/translator attribution are removed.
