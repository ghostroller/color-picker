## M1 · 常驻外壳

状态：**已满足进入 M2 的门槛**。
此前 40 项默认测试和 2 项显式桌面冒烟测试通过；2026-09-20 用户反馈正常触发，
日志确认实际快捷键、Shell 通知显示、托盘激活与设置入口。实际 Explorer 重启和长按热键
仍保留未测记录，不将这些项目或后续发布矩阵冒充已经全部通过。

已实现：

- 隐藏的普通顶层宿主、阻塞消息循环，单独处理 GetMessage 的 -1 / 0。
- 托盘 Version 4、三个菜单项、阶段提示和 TaskbarCreated 重建；重建失败有序退出，
  避免留下没有托盘入口的隐藏进程。
- 当前登录 / Windows 会话范围的单实例互斥对象；二次启动有限重试向原宿主发送激活。
- 默认 Ctrl+Alt+C、MOD_NOREPEAT；冲突时提示且保留托盘入口。
- WTS 通知注册 / 注销；显示、会话、电源、系统退出消息接入。
- 回调只写入主线程 Cell 待办，离开回调后执行 Win32 副作用；不持有跨重入的应用可变借用。
- 热键、会话通知、托盘先释放，再销毁宿主与类，最后释放单实例句柄。
- 独立、默认忽略的 Windows 桌面冒烟测试；诊断查询不创建周期性工作。

当前激活只显示 M1 提示，设置只显示阶段说明，这是计划规定的阶段入口。

## M1 诊断补充 · 快捷键无可见效果

- 新增 `--log-file <路径>`，默认关闭日志；原有 `--diagnostics` 仍仅打开状态查询。
- 记录启动、DPI、单实例转交、热键注册结果、热键激活、托盘通知提交 / Shell 显示回调和退出。
  日志在窗口回调返回后写入，不记录一般按键或屏幕内容。
- UTF-8 追加，单写者，容量最多 1 MiB，超限有明确标记；无后台日志线程或定时器。
- `scripts/start-with-logs.ps1` 构建独立诊断 EXE，创建唯一日志并打印实时查看命令。
  已有用户实例不会被脚本关闭，需先从托盘退出旧实例才能记录新进程的热键。
- 验证：51 项默认测试、Clippy、Release、manifest 和运行时 DPI 通过；Release 的
  `--check-environment --log-file` 已实际写出包含中文 / 空格路径的日志；缺失路径返回码 2。
- 桌面测试已补日志断言，当前用户已有运行实例，因此本次未重跑默认忽略的桌面测试。
  尚未通过用户实际按键日志确认“无效果”的具体原因，不能据此断言热键冲突或通知被隐藏。
