## M1 · 常驻外壳

状态：**已满足进入 M2 的门槛**。
此前 40 项默认测试和 2 项显式桌面冒烟测试通过；2026-09-20 用户反馈正常触发，
日志确认实际快捷键、Shell 通知显示、托盘激活与设置入口。实际 Explorer 重启和长按热键
仍保留未测记录，不将这些项目或后续发布矩阵冒充已经全部通过。

已实现：

- 隐藏的普通顶层宿主、阻塞消息循环，单独处理 GetMessage 的 -1 / 0。
- 托盘 Version 4、三个菜单项、阶段提示和 TaskbarCreated 重建；重建失败有序退出，
  避免留下没有托盘入口的隐藏进程。
- 当前登录 / Windows 会话范围的单实例互斥对象；二次启动有限重试向原宿主发送激活。
- 默认 Ctrl+Alt+C、MOD_NOREPEAT；冲突时提示且保留托盘入口。
- WTS 通知注册 / 注销；显示、会话、电源、系统退出消息接入。
- 回调只写入主线程 Cell 待办，离开回调后执行 Win32 副作用；不持有跨重入的应用可变借用。
- 热键、会话通知、托盘先释放，再销毁宿主与类，最后释放单实例句柄。
- 独立、默认忽略的 Windows 桌面冒烟测试；诊断查询不创建周期性工作。

M1 提交中的激活只显示阶段提示，设置只显示阶段说明，这是计划规定的阶段入口。
M1 阶段未安装 timer/hook、未创建应用工作线程、未采样屏幕、未做网络 I/O。

## M2 · 实时取色预览

状态：**实现完成，当前桌面受控测试及用户预览反馈通过；跨屏实机验收待补。**
用户明确要求直接推进至 M5，减少测试，因此跨屏矩阵留到发布前补齐，不阻塞本次开发。

已实现：

- 按当前物理鼠标坐标采样：复用屏幕 DC、内存 DC 和 1×1 top-down DIB，
  `BitBlt(SRCCOPY | CAPTUREBLT)` 后 `GdiFlush` 读取 RGB。
- 活动会话请求 17ms 定时器；静止鼠标继续采样动态画面，颜色和坐标不变时不重新绘图。
- 非激活、置顶、鼠标穿透的 GDI 缓冲预览：颜色、HEX、物理坐标和托盘停止提示。
  工作区避让鼠标、DPI 布局与字体缓存，不改变系统光标。
- 自身窗口覆盖新采样点时先隐藏并刷新 DWM，捕获排除标志仅作辅助；禁用自身窗口转场。
- 托盘可开始 / 停止；显示、会话或电源变化停止预览。菜单打开期间暂停采样，关闭后恢复。
  活动会话的重复激活在接收时忽略，避免积压消息抵消菜单停止操作。
- 会话与定时器代际独立递增，旧消息不能操作新会话。停止先释放 timer，再释放窗口 / GDI，
  Idle 不采样、不保留 timer；尚未创建输入线程或钩子。
- 单次采样失败清除旧颜色，连续失败停止并提示；开始 / 停止 / 故障记录离散日志，
  不按帧记录颜色或屏幕内容。
- 已知像素测试窗口、像素准确性测试、提示窗口非激活 / 资源回归测试、宿主启停隔离测试。

验证：Windows 格式、Clippy、65 项默认测试、Release、嵌入 manifest 和运行时 PMv2 检查通过；
5 项显式桌面测试通过。采样器 100 次循环的 GDI 对象保持 2→2；提示窗口 100 次循环
的 GDI / USER 对象保持 3 / 2，未发现增长。详细边界见 [验证记录](validation.md)。

M2 提交尚不接管点击或滚轮，也不支持 Esc 取消、冻结放大和结果复制。使用 `scripts/start-with-logs.ps1`
构建并启动新版本，按 Ctrl+Alt+C 预览，通过托盘“停止预览”结束。

## M3 · 输入与选择

- 接入已有状态机：资源与输入线程均就绪才进入 Live；确认或取消进入 Finishing，
  保持主线程消息循环，输入线程退出并回收后才释放会话资源、展示结果。
- 会话专属输入线程安装鼠标与 Esc 低级钩子，成对消费按钮 / Esc；候选确认期间不重复选择，
  无效候选可继续取色；其他键与鼠标移动正常传递，滚轮不穿透。
- 启动前拒绝已按住的鼠标或 Esc；离散事件队列有界，移动通知合并，旧会话事件隔离。
  队列 / 通知故障取消；异常释放有 5 秒上限，正常关闭异步等待已消费手势释放。
- 左键抬起坐标重新采样，拒绝用旧预览值充当结果；暂用托盘通知展示确认结果，M5 替换为原生窗口。
- 按用户要求只做必要检查：编译及现有默认测试、关键输入配对协议回归；未用模拟输入操作用户桌面。
  实际低级钩子在不同应用权限、桌面切换下的输入不穿透验收仍待补。

阶段提交：`59cec35`。

  低于 4× 时销毁放大镜 / 快照并恢复实时采样。

  最终事件，避免晚到取消被误当作确认结果。
- 必要检查：编译、Clippy、滚轮余量和 DPI 布局纯测试；复用既有 13 项映射测试。
  增补快照准确性的默认忽略测试，未自动运行跨屏 / 键鼠实机矩阵。

## M5 · 结果与复制

- 完成从实时 / 冻结确认、成对释放输入、回收线程及取色资源，到结果窗口的完整接线。
- 原生 STATIC / 只读 EDIT / BUTTON 控件展示色块、物理源坐标、来源及四种格式；
  显示和复制复用 format_color，支持 Tab / Enter / Esc，关闭即销毁，重新取色或快捷键开始新会话。
- 复制使用真实 HWND、CF_UNICODETEXT 与可移动内存；成功后才向系统转移所有权。
  剪贴板占用最多重试 3 次、间隔 50ms；每次新请求与重试使用新 timer token，关闭后取消。
  成功 / 失败在窗口内显示，保留取色结果，不使用阻塞等待或后台轮询。
- 默认格式 HEX，自动复制关闭；设置与持久化仍属于 M6，不在本次范围。
- 遵照用户“直接到 M5、不需要过多测试”的要求，复用现有逻辑检查并只补必要的输入协议、
  滚轮、布局、剪贴板重试 / 内存检查和一个原生窗口冒烟；多屏、完整真实输入矩阵与压力测试留待后续。

最终验证：72 项默认测试、Clippy、Release、manifest 与运行时 DPI 全部通过；一次短桌面冒烟
4 项通过（冻结快照、放大镜 / 结果控件、2 项宿主启停）。未合成键鼠输入或改动用户剪贴板。

## M6 · 设置与恢复

用户实测 M3–M5 后反馈“看起来没问题”，授权继续 M6–M7；此反馈是体验确认，
不代替逐项硬件矩阵。M6 功能实现完成：

- 原生设置窗口修改 Ctrl/Alt/Shift + A–Z / 0–9 / F1–F11、默认格式和自动复制；
  显式应用，关闭销毁；打开期间阻止所有取色入口，无设置监视线程或周期定时器。
- Known Folder 配置路径，schema / 字段 / 枚举 / 组合键严格校验；缺失使用默认值。
  损坏、读取错误和未来版本保留原文件、提示一次、禁止覆盖，并给出修复/移走后重启的恢复路径。
- 同目录唯一临时文件完整写入、同步、关闭、原子替换；失败保留旧文件并清理临时文件。
  保存前再次校验原文件，检测临时写入期间的外部改动。
- 快捷键事务先注册新 ID、保存配置，再发布新 ID 并注销旧键；临时和已退休 ID 均不激活。
  注册或保存失败保持旧配置 / 旧键，允许留在设置窗口重试。
- 结果窗口使用配置的默认格式；自动复制排入 UI 操作，在输入线程及采样资源回收后执行。
- 显示 / 会话 / 电源变化停止当前取色且不自动恢复；Explorer 通知仅恢复托盘。
  优先处理已收到的取消/退出，防止 Finishing 的旧候选被提升为结果并自动复制。

验证结果记录于 [验证记录](validation.md)；真实锁屏、休眠、RDP 和显示器拔插继续待实机验收。
